Understanding NetScaler IP Types:
- **NSIP (NetScaler IP):** The management IP address used for direct access to the appliance.
- **VIP (Virtual IP):** The IP address associated with a physical server or server farm represented by a virtual server.
- **SNIP (Subnet IP):** Used for connection management and server-side communication within a specific subnet.
- **MIP (Mapped IP):** Legacy IP type used for server-side connections when SNIP is not used.
